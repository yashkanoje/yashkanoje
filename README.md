## 🚀 Featured projects

### [Vehicle Analytics](https://github.com/yashkanoje/vehicle-analytics)
Offline traffic analytics from fixed-camera video: tracks every vehicle, measures speed with an error bar from a
ground-plane calibration, keeps a SQLite record per vehicle, flags rule violations, drafts challan PDFs, and has a
local review dashboard.
On a 60-second motorway clip it counted 83 / 75 vehicles against a hand count of 83 / 74.
`YOLO` `DeepSORT` `OpenCV` `SQLite` `Streamlit` `pytest` · 351 tests, CI on GitHub Actions

<a href="https://github.com/yashkanoje/vehicle-analytics"><img src="https://raw.githubusercontent.com/yashkanoje/vehicle-analytics/main/docs/dashboard_overview.png" width="640" alt="Vehicle Analytics dashboard overview"/></a>

### [VidyaDesk](https://github.com/yashkanoje/vidyadesk)
AI enquiry assistant for coaching institutes: answers students and parents on Telegram in English, Hindi, Hinglish or
Odia, quotes fees only from the institute's own facts, turns each chat into a lead, and gives the owner a phone-first
dashboard. Multi-tenant, with each institute seeing only its own data.
`LangGraph` `FastAPI` `PostgreSQL` `pgvector` `Gemini / Claude` · CI on GitHub Actions
